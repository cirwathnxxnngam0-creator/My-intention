เจตจำนงของความคิด — เว็บส่วนตัว (HTML/CSS/JS ล้วน ไม่มี backend)

เปิดใช้งาน
  1) ดับเบิลคลิก index.html  (ใช้ได้ทันที)
  2) ติดตั้งเป็นแอป + ออฟไลน์ + ตรวจอัปเดตเอง: เปิดผ่านเซิร์ฟเวอร์ในเครื่อง
       npx serve            (แล้วเปิดที่อยู่ที่ขึ้นมา)
       python -m http.server 8080   (แล้วเปิด http://localhost:8080)
     แล้วไปที่หน้า "ตั้งค่า" กด "ติดตั้งเป็นแอป"

หน้า (หลักคำสอนคือหัวใจ · หน้าแรกมี 5 ห้อง · ตั้งค่าอยู่ท้ายทุกหน้า)
  index.html      หน้าแรก: แนะนำเว็บ + 5 ห้อง
  schools.html    ห้อง 1 สำนักคิด: ค้นหา · หลักคำสอนรายสำนัก
  school.html     หน้าสำนัก (#id): หลักคำสอนของสำนัก · ตัวบทและคำแปล · สรุป · การตีความของฉัน
  poems.html      ห้อง 2 เจตจำนง (กลอน): กลอนของฉัน · เขียนกลอน · ให้นักปราชญ์อ่าน · ฉันทลักษณ์
  brain.html      ห้อง 3 สมองและสารสื่อประสาท 6 ชนิด
  sages.html      ห้อง 4 พูดคุยกับนักปราชญ์: ข้อคิดประจำวัน · ค้นหา · นักปราชญ์และหลักคำสอน
  sage.html       หน้านักปราชญ์ (#id): หลักคำสอน (+ แท็บแง่มุม) · สนทนา · การตีความของฉัน · เบื้องหลังการจำลอง
  notebook.html   ห้อง 5 สมุดบันทึก: บันทึกอิสระ · การตีความทั้งหมด · บทสนทนา · ค้นหาในสมุด
  settings.html   ตั้งค่า (ลิงก์อยู่ท้ายทุกหน้า): ติดตั้งแอป · ตรวจหาอัปเดต · เชื่อม Claude · สำรองสมุด · เกี่ยวกับภาพ
  keep.html       หน้าเก่า ส่งต่อไป settings.html

ข้อมูล
  js/data.js      สำนักคิด สารสื่อประสาท เลขรุ่น
  js/sages.js     นักปราชญ์ — สร้างอัตโนมัติจาก project-2 (อย่าแก้ตรงนี้ แก้ที่ project-2/profiles แล้วรัน node build-sages.mjs)
  img/            ภาพวาดด้วยโค้ด: ฟ้าดาวแบบฟัน โคค (scene-*.svg, bg-night.svg) และสระบัวแบบโมเนต์ (pond.svg)

ออกรุ่นใหม่ (เพื่อให้ปุ่ม "ตรวจหาอัปเดต" เห็นของใหม่)
  1) แก้ไฟล์ตามต้องการ
  2) ในโฟลเดอร์นี้ รัน:  node release.mjs 1.2.0 "สิ่งที่เปลี่ยน 1" "สิ่งที่เปลี่ยน 2"
     → เขียนเลขรุ่นใน js/data.js, สร้าง version.json และ download/jetchamnong-site.zip
  3) แอปที่ติดตั้งไว้จะยังใช้รุ่นเดิมจนกว่าผู้ใช้จะกด "ตรวจหาอัปเดต" → "อัปเดตเดี๋ยวนี้"
  ห้ามแก้ sw.js ถ้าไม่จำเป็น: ถ้า sw.js เปลี่ยน เบราว์เซอร์จะเปลี่ยนตัวจัดการออฟไลน์เอง (แต่ไฟล์เว็บยังรอผู้ใช้กดอัปเดต)
