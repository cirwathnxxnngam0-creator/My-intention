วิธีติดตั้งด้วยตนเอง
  1. ดาวน์โหลดไฟล์เว็บ (ZIP) แล้วแตกไฟล์ไว้ในเครื่อง
  2. เปิด index.html ได้ทันที อ่านและเขียนบันทึกได้เลย
  3. ติดตั้งเป็นแอปและใช้ออฟไลน์เต็มรูปแบบ ต้องเปิดผ่านเซิร์ฟเวอร์ในเครื่อง: เปิด Terminal ในโฟลเดอร์ พิมพ์ npx serve หรือ python -m http.server 8080 แล้วเปิดที่อยู่ที่ขึ้นมา
  4. กด “ติดตั้งเป็นแอป” ด้านบน หรือไอคอนติดตั้งในแถบที่อยู่ (Chrome, Edge) หรือ “เพิ่มลงหน้าจอโฮม” บนมือถือ

บันทึกผูกกับที่อยู่ที่เปิด การเปิดจากไฟล์โดยตรงกับการเปิดผ่าน localhost จึงมีบันทึกคนละชุด ใช้สำรองและนำเข้าด้านล่างเพื่อย้าย

แอปจะไม่อัปเดตเอง จะตรวจเมื่อคุณกดปุ่มเท่านั้น และจะเปลี่ยนเวอร์ชันเมื่อคุณกดยืนยัน บันทึกของคุณไม่ถูกแตะ

    ตั้งค่า · นักปราชญ์

    เชื่อม AI

    เลือกผู้ให้บริการ AI แล้วใส่กุญแจ API ของคุณ นักปราชญ์จะตอบในหน้าเว็บได้เลย ใช้ได้ทั้ง Claude, ChatGPT, Gemini, OpenRouter (รวมโมเดลจากหลายร้อยแห่งด้วยกุญแจเดียว) และบริการใดก็ได้ที่ใช้รูปแบบเดียวกับ OpenAI รวมถึงโมเดลที่รันบนเครื่องคุณเอง ถ้าไม่เชื่อม ยังกด “คัดลอกคำสั่ง” ไปวางในแชต AI ใดก็ได้

    กุญแจเก็บในเบราว์เซอร์ของเครื่องนี้เท่านั้น ไม่รวมอยู่ในไฟล์สำรอง และถูกส่งตรงไปที่ผู้ให้บริการที่คุณเลือกเมื่อกดส่งข้อความเท่านั้น อย่าใส่กุญแจในเครื่องที่ใช้ร่วมกับผู้อื่น ค่าใช้จ่ายคิดตามบัญชีของคุณกับผู้ให้บริการนั้น
